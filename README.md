# Warehouse Management System

## Introduction

The Warehouse Management System (WMS) is a web-based application developed to manage warehouse operations efficiently. The system helps in handling inventory, products, storage bins, receiving operations, authentication, and security management. It provides a centralized platform for monitoring warehouse activities and improving operational efficiency.

## Goal

The main goal of this project is to:

* Manage warehouse inventory efficiently.
* Track products and storage locations.
* Improve warehouse operations through automation.
* Provide secure user authentication and authorization.
* Generate QR codes and barcodes for product tracking.
* Ensure system security through JWT authentication and encryption.
